收藏夹工作区管理系统

Bookmark Workspace Manager

关于本扩展

本扩展旨在帮助您高效管理浏览器收藏夹，通过"工作区"的概念，将传统书签栏中的顶层文件夹抽象为可快速切换的工作区。

支持多列树状视图、全局搜索、多主题切换、面板缩放、双面板对比，以及基于 GitHub Gist 的多端同步功能。

主要功能

  • 工作区管理：将书签栏文件夹作为工作区，一键切换
  • 多列树状视图：横向展开，直观体现文件夹层级
  • 全局搜索：实时过滤所有书签（标题、URL、路径）
  • 双面板对比：同时查看两个工作区
  • GitHub Gist 同步：上传/下载/自动同步，跨设备保持一致
  • 跨浏览器兼容：Chrome、Edge、Firefox

作为一名长期与代码、服务器和项目打交道的 IT 从业者，我深刻理解高效管理信息和资源的重要性。本扩展正是为了解决我日常工作中书签数量庞大、层级复杂、查找不便的痛点而诞生。
